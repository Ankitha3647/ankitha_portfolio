# Ankitha K M — 3D Portfolio Website

A personal 3D developer and data science portfolio built with **React 18, TypeScript, Three.js, React Three Fiber, and GSAP**.

Showcasing end-to-end projects across **Data Analytics, Machine Learning (Random Forest & XGBoost), Deep Learning (Computer Vision & CNN), Business Intelligence (Power BI), and Embedded IoT**.

---

## 🌟 Key Features

- **Interactive 3D Experience:** Character and physics-driven 3D scene powered by `@react-three/fiber`, `@react-three/rapier`, and Three.js.
- **GSAP Animations:** Smooth scroll reveals (`ScrollSmoother`, `ScrollTrigger`), text splitting (`SplitText`), and interactive mouse-tracking effects.
- **Categorized Technical Skills:** Interactive skill cards spanning Programming Languages, Data Analytics, ML, Deep Learning, BI Visualization, Hardware, and Tools.
- **Featured Project Showcase:** Carousel showcasing:
  1. *Smart Agriculture – Crop Yield Prediction (ML & Streamlit)*
  2. *Garbage Segregation & Classification (Deep CNN & TrashNet)*
  3. *Amazon Sales Data Analytics & BI Dashboards (Power BI & Python)*
  4. *Mood-Based Music Recommendation System (Python & Flutter)*
- **Industrial Experience & Academic Journey:**
  - *Automotive Axles Limited (Mysore)* — Technical Apprentice
  - *Tata Electronics Systems and Solutions (Bangalore)* — Technical Intern
  - *Government Residence Women Polytechnic College, Shivamogga* — Diploma in E&C (CGPA: 9.56 / 10.0 Distinction)
  - *A-CUBE Tech Skills Lead* — 4 Professional Certifications
- **Direct Resume Integration:** Direct downloads for both the ATS-friendly PDF (`Ankitha_K_M_Professional_Resume.pdf`) and editable Word document (`Ankitha_K_M_Professional_Resume.docx`).
- **Interactive Contact Section:** Pre-configured direct messaging, phone, email, and social links.

## 🛠️ Tech Stack

- **Frontend & Core:** React 18, TypeScript, Vite
- **3D & Physics:** Three.js, `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`
- **Animation & Transitions:** GSAP, `@gsap/react`, ScrollSmoother, ScrollTrigger, SplitText
- **Icons & Styling:** React Icons (`react-icons`), CSS3 custom properties

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Installation & Run

1. Install project dependencies:
   ```bash
   npm install
   ```

2. Start the local Vite development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
